# Dark War QR for Google TV

A tiny Android TV launcher app that opens the Dark War Survival shop login directly in TV Bro:

https://pay.darkwar-survival.com/#/login

It prefers TV Bro because TV Bro is designed for Android/Google TV remote control. If TV Bro is not installed, it falls back to the TV's default browser.

## Build without installing Android Studio

This project includes a GitHub Actions workflow.

1. Create a GitHub repository.
2. Upload this project.
3. Open **Actions**.
4. Select **Build Dark War QR APK**.
5. Choose **Run workflow**.
6. When it finishes, download the `Dark-War-QR-APK` artifact.
7. Inside the downloaded ZIP is `app-debug.apk`.

The APK is a debug-signed sideloadable build intended for personal use.

## TV setup

Install **TV Bro** from Google Play on the TV first.

Then install `app-debug.apk`. The installed app is called **Dark War QR** and is a TV/Leanback app, so it should appear in the TV's app list.

Selecting it opens a fresh Dark War login page in TV Bro. The QR code is therefore regenerated by the website rather than being stored in the APK.

## Direct APK install with ADB

Enable Developer Options and USB/Wireless debugging on the TV, then from a computer on the same network:

    adb connect TV_IP_ADDRESS
    adb install app-debug.apk

Android 14 may ask you to approve the computer on the TV.
